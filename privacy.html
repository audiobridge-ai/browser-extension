AudioBridge

Privacy Policy

Last updated: 2026-01-02

AudioBridge respects your privacy.

Data Collection

AudioBridge does not collect, store, or transmit user data to any developer-controlled servers.

Data Processing

The extension processes the following data solely to provide its functionality:

  • Audio recordings from the user’s PLAUD account
  • Transcription text generated using the user’s selected API
  • User-provided API configuration (API key and endpoint)

All processing is initiated by the user and performed locally or directly between the user’s browser and the selected API provider.

Data Storage

Any configuration data or temporary files are stored locally on the user’s device and can be removed by uninstalling the extension.

Data Sharing and Disclosure

AudioBridge does not sell, rent, or share Google user data with advertisers or unrelated third parties.

Google user data is disclosed only in the following limited circumstances:

  • To Google services (such as Google Drive) when the user explicitly authorizes an export or upload action.
  • To third-party transcription or summarization API providers explicitly configured by the user, using the user’s own API credentials.

AudioBridge does not transmit Google user data to any developer-controlled servers. All data transfers occur directly between the user’s browser and the selected third-party service.

Data Protection and Security

AudioBridge implements the following measures to protect user data:

  • All network communication with third-party services is performed over HTTPS.
  • API credentials are stored locally in the user’s browser and are never transmitted to developer-controlled servers.
  • Audio files and transcripts are processed only when explicitly initiated by the user.
  • Temporary data and configuration data can be fully removed by uninstalling the extension.

AudioBridge does not retain Google user data beyond what is necessary to complete the user-initiated action.

Third-Party Services

AudioBridge communicates only with the following third-party services, as explicitly configured or authorized by the user:

  • Google Drive (for user-initiated file export)
  • PLAUD web services
  • The API endpoint specified by the user

AudioBridge does not use analytics, tracking, advertising services, or background data collection mechanisms.
